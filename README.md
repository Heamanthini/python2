# 📅 Daily Planner Web App

A **modern, responsive, and minimalistic daily planner app** built with **HTML**, **CSS**, and **JavaScript**.  
This app allows you to **plan your day by hour**, add tasks, mark them complete, and manage your schedule visually.

---

## 🎯 Features
✅ **Add tasks by time slot**  
✅ **Mark tasks as completed** (strikethrough style)  
✅ **Delete tasks instantly**  
✅ **Auto-highlight current hour**  
✅ **General add-task area** for quick notes  
✅ **Fully responsive** – works on mobile and desktop  

---

## 🛠 Tech Stack
- **HTML5**
- **CSS3** (Flexbox, Responsive, Google Fonts)
- **Vanilla JavaScript (ES6)** – handles task interactions and updates
